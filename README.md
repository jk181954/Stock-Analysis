# 股票客觀分析終端

單一 HTML 檔案，輸入股號（台股數字代號如 2330，或美股代號如 AAPL），
抓取歷史股價、計算均線（MA20/MA60）、RSI、年化波動度、52週高低點，
並用規則化邏輯產生客觀技術面摘要；台股額外顯示證交所公開的基本面資料（產業別、本益比、殖利率、股價淨值比等）。

## 為什麼需要「代理」這個額外步驟？

實測已確認：`openapi.twse.com.tw`（台股基本面）沒有開放瀏覽器跨網域讀取；
股價資料來源原本測試過 `stooq.com`，但實測發現它會對非真人瀏覽器的請求（含伺服器代理）
要求 JavaScript 人機驗證，無法用於自動化抓取，因此改用 **Yahoo Finance** 的公開股價 API。

不論哪一種情況，解法都一樣：加一層「代理」，由一個小型伺服器程式（不是瀏覽器）去跟這些來源要資料
（伺服器對伺服器沒有跨網域限制、也比較不會被誤判為機器人），再由這個代理伺服器附上開放跨網域的標頭回傳給你的網頁。
這裡用 **Cloudflare Workers** 來架這個代理，免費方案每天 10 萬次請求，足夠個人使用，不需要信用卡。

> **這次 `worker.js` 又更新了（白名單改成 `mopsfin.twse.com.tw`，取代會擋程式化請求的 `www.tpex.org.tw`），
> 請重新把新版內容貼到 Cloudflare Worker 的 Edit code 頁面並重新 Deploy 一次。**

### 上櫃股票基本面的已知限制

上櫃公司基本資料（產業別、董事長、上櫃日期、實收資本額）取自公開資訊觀測站，正常運作。
但「本益比、殖利率、股價淨值比」這三個數字目前只公開在櫃買中心官網（`tpex.org.tw`），
該網站對非瀏覽器的程式化請求有防護機制（實測回傳 HTTP 520），暫時沒有穩定的方式取得，
這部分會顯示「暫時無法取得」而不是編造數字。

## 部署步驟

### 第一步：架 Cloudflare Worker 代理

1. 到 https://dash.cloudflare.com/sign-up 免費註冊一個帳號（只需要 Email）。
2. 登入後左側選單找 **Workers & Pages**，按 **Create**（建立）。
3. 選 **Create Worker**，取一個名字（例如 `stock-proxy`），按 **Deploy** 先部署一個預設的樣板。
4. 部署完成後按 **Edit code**（編輯程式碼），把畫面上原本的程式碼**全部刪掉**，
   貼上這個資料夾裡 `worker.js` 的完整內容，按右上角 **Deploy** 儲存部署。
5. 部署成功後，畫面上會顯示這個 Worker 的網址，格式類似：
   `https://stock-proxy.你的帳號.workers.dev`
   把這個網址記下來，等一下要貼到網頁設定裡。

### 第二步：部署網頁到 GitHub Pages

1. 到 https://github.com 建立一個新的 Repository。
2. 把 `index.html` 上傳到 Repository 根目錄（網頁上的「Add file → Upload files」即可）。
3. 進入 Repository 的 **Settings → Pages**，Source 選 **Deploy from a branch**，
   Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等 1–2 分鐘，會出現網址，格式類似：`https://你的帳號.github.io/你的repo名稱/`

### 第三步：把代理網址接進網頁

1. 打開剛剛部署好的 GitHub Pages 網址。
2. 在頁面上「代理網址」欄位，貼上第一步拿到的 Cloudflare Worker 網址（例如 `https://stock-proxy.你的帳號.workers.dev`），按「儲存」。
3. 這個設定會存在你目前使用的瀏覽器裡（下次打開同一台電腦、同一個瀏覽器不用再設一次；換裝置或換瀏覽器要重新貼一次）。
4. 輸入 `2330` 或 `AAPL`，按「分析」測試。

## 如果還是失敗

頁面輸入框下方有「連線診斷」連結，點下去會分別測試：
- 代理 → Yahoo Finance（股價）是否成功
- 代理 → TWSE OpenAPI（上市基本面）是否成功
- 代理 → 公開資訊觀測站（上櫃基本面）是否成功
- 目前設定的代理網址與頁面來源

把診斷結果的文字截圖回饋，會比單純說「失敗」更容易定位問題。

## 已知限制

- 台股基本面涵蓋證交所「上市」與公開資訊觀測站「上櫃」公司的公司基本資料；興櫃股票不在涵蓋範圍內。
- 上櫃股票的本益比／殖利率／股價淨值比、月營收、三大法人買賣超、融資融券暫時無法取得
  （這些資料的官方來源在櫃買中心網站，該網站對程式化請求有防護機制）。
- 月營收、三大法人買賣超、融資融券僅涵蓋證交所「上市」股票，且為最近一個交易日的全市場快照
  （非該股號專屬查詢，程式會在下載後於瀏覽器內篩選對應股號）。
- 美股目前沒有基本面、營收、籌碼資料。
- 自選股清單、K線圖為純前端功能，不受上述資料來源限制影響。
- Cloudflare Worker 免費方案有每日請求上限（10 萬次/天），一般個人使用不會碰到。
- 分析內容完全是規則化計算生成的客觀描述，不構成投資建議。
